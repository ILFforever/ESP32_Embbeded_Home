Arduino888 Smart Home — three redesign directions

Static mockups only. Nothing here is wired to the app or the API; the numbers are representative sample readings. Pick a direction (or parts of several) and it gets built into the real dashboard afterwards.

Direction A

Bureau

Treats the dashboard as a printed instrument sheet. Hairline rules do all the containment, so there are no cards, shadows or rounded corners to date the design. Readings are the largest thing on the page; chrome is nearly invisible.

Palette
Type
Bahnschrift (condensed) for figures · Segoe UI body · Consolas for IDs and timestamps
Structure
Summary band across the top, then a wide telemetry column beside a narrow events column.
Best if
You want it to read as serious lab equipment and photograph well in a report or poster.

Direction B

Panel

Keeps a dark interface but strips every effect that dates the current one — no blur, no glow, no gradient, no navy. Flat graphite panels divided by 1px seams, monospace throughout, everything aligned to a column. Reads as lab hardware rather than a web app.

Palette
Type
Consolas throughout, tabular figures, uppercase tracked labels
Structure
Icon rail, status strip, then a seamed panel grid — device matrix, alarm log, gauges, access.
Best if
You want maximum data density and a look that matches the embedded hardware itself.

Direction C

Plan

Changes the information architecture, not just the skin: the house itself is the navigation. Readings sit where the hardware physically is, so "412 ppm in the garage" is a place before it is a row in a table. Quiet drafting palette, light numerals, mono reserved for annotation.

Palette
Type
Segoe UI Light for figures · Segoe UI body · Consolas for pins and labels
Structure
Floor plan with live pins, a context stack beside it, device roll-call underneath.
Best if
You want the demo to land instantly with an audience who has never seen the system.

Direction D

Glass

Liquid Glass treated as a material, not a filter. Depth comes from a specular top edge, a three-stop shadow stack and concentric corner radii — not from glow. The wallpaper behind is desaturated almost to neutral so the glass has something quiet to refract; colour appears only where a reading needs attention.

Palette
Type
SF Pro Display on Mac, Segoe UI Variable on Windows · light tabular numerals at −0.03em
Structure
Floating toolbar, large title, attention card, stat strip, then a restrained bento.
Best if
You want it to feel like a shipped consumer product rather than an engineering readout.
